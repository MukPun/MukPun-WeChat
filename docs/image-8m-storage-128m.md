# 图片与隔离存储容量

2026-10-28 源码调整；线上生效与验收记录见本文末尾。只涉及本项目，不改变 Docker、AstrBot、FRP、宿主路由、防火墙或内核模块。

## 容量含义

Native 的私有 `/var/lib` 是受限 tmpfs，原有 32MiB 是本项目早期验证时的保护值，不是微信要求。调整为 **128MiB** 后仍有硬上限；tmpfs 按实际使用量消耗内存，并计入 Native cgroup，不会在启动时一次占满 128MiB。

SDK 将上传源以加密负载保存在自己的 SQLite。一次发送还会短暂使用解码、Base64、HTTP 上传及 JPEG 准备内存。两者是不同资源：发送结束后 Python 临时内存可释放，但 SDK 缓存和本项目的完整会话快照不会随函数返回消失。

| 资源 | 本次源码上限 |
| --- | --- |
| 输出图片源 | 8MiB；超过拒绝，不为迁就上限自动压缩 |
| 图片尺寸 | 每边 2048，总像素 4×1024×1024 |
| WS action | 16MiB，包含 Base64 和 JSON 膨胀 |
| IPC | 单帧 256KiB；原始图片每块 64KiB、逐块确认 |
| Native tmpfs / 单文件 | 128MiB / 128MiB |
| Native 父 cgroup | max/high 384/288MiB、20% CPU、32 tasks、无 swap |
| Native SDK 单元 | max/high 256/192MiB，共享父 cgroup |
| Native 转发进程 | max/high 96/72MiB、4 tasks，共享父 cgroup |
| OneBot | max/high 128/96MiB、10% CPU、8 tasks |
| 根控制器 | 保持 max/high 64/48MiB、5% CPU、16 tasks |
| 会话快照 | 源文件合计 128MiB、ZIP 132MiB、对象数仍最多 1024 |

桥不会额外重编码或压缩图片。固定 `agent-wechat v1.0.0-beta.8` 的普通图片发送实现仍准备 JPEG 变体，不能承诺原图字节不变或无损。该限制见 [固定版本图片实现](https://github.com/thisnick/agent-wechat/blob/v1.0.0-beta.8/packages/native-client-rust/crates/wechat-core/src/media.rs)。本次不修改 SDK 二进制。

## 运行中保护

- 新上传先检查真实 tmpfs、父组内存、数据库及 WAL/journal、Native 实际单文件限制。保留 16MiB 存储与 64MiB 内存余量，额外按 `max(1MiB, 2×源大小+512KiB)` 预留单次增长。
- 图片输入在空间不足 32MiB、数据库到文件上限余量不足 32MiB，或父组内存余量不足 64MiB 时暂停新取图。独立文本继续接收；带文字的问题保留文字，不伪造图片。
- 根控制器每两秒更新容量准入，启动 SSE 前先下发初始状态。状态包括存储总量、已用量、空闲量和 `media_capacity_available`。
- 同一 Native 运行期内，只有上传回执核验通过的源 UUID 才能缓存复用；按源摘要/字节数/MIME 匹配，最多 64 项、24 小时。新 Native 运行期不会盲用旧 UUID。复用仍逐次校验发送作业和微信回执，不复用发送结果、不自动重发。
- 保留原持久上传计数；移除 16 次试运行门槛，改为有限百万次计数保护。计数不替代真实容量检查，也不因失败清零。

## 恢复前回收

`SessionHost.start()` 仅在线上会话安全停止后、替代 Native 启动前，对离线快照的私有副本尝试回收。不会因容量压力自动停止会话或触发扫码。

仅回收本桥命名的上传源，且每个关联作业都必须满足 accepted/completed、微信服务端确认、源摘要绑定、上传读回验证及投影完成。通常至少保存 24 小时；快照大于等于 64MiB 时，只对超过 60 秒的已完成源做压力回收，尽量保留 32MiB 源缓存。未完成、未知、无核验依据的源均保留。

清理只修改 `media_sources`；其他 SQLite 表逐行计算摘要，全部非数据库文件核对大小/CRC，之后重新检查数据库。VACUUM 仅在宿主私有磁盘副本上执行。新快照验证成功才原子安装，原始快照保留为 previous；失败保留原资料并跳过优化。

这不是完整 SDK 媒体清理器：接收缓存、SDK 媒体资产、managed profile 附件、消息与回执不在清理范围。仍不能保证永不耗尽空间或无限期运行；达到门槛先暂停图片。Native 单次七天期限也保持不变。
